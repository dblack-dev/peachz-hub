  1. เปิดใช้บริการ API ที่ Cloud Translation API Library ↗ (เลือกโปรเจกต์ที่ผูก Billing แล้วกด Enable; ฟรี 500,000 ตัวอักษรแรก/เดือน)
  2. ไปที่ APIs & Services → Credentials ↗ แล้วกด + Create Credentials → API key
  3. กดแก้ไขคีย์ที่เพิ่งสร้าง → Application restrictions เลือก Websites เพิ่ม https://dblack-dev.github.io/* (ป้องกันคนอื่นแอบเอาคีย์ไปใช้)
  4. ส่วน API restrictions เลือก Restrict key → ติ๊กเลือกเฉพาะ Cloud Translation API แล้วกด Save จากนั้นนำคีย์มาวางในช่องด้านบน
